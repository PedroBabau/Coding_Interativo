— sobre o projeto

Este portfólio foi desenvolvido no âmbito da unidade curricular de Edições Multimédia Interativa com p5.js. Cada projeto explora diferentes formas de interação entre o utilizador e o sistema, criando experiências visuais únicas e dinâmicas.


Os projetos seguem os princípios de design responsivo, adaptando-se a diferentes dispositivos e tamanhos de ecrã, e implementam múltiplos tipos de interação para uma experiência imersiva.

  • p5.js — biblioteca principal
  • p5.sound — processamento de áudio
  • HTML5 / CSS3 — estrutura e estilo
  • JavaScript ES6+ — lógica interativa
  • Design responsivo — multi-ecrã
  • GitHub Pages — Coding Interativo
